## 📖 Overview

**Ibrahim AI Studio** is an advanced AI-powered desktop application that combines multiple AI tools into one powerful workspace. It helps users generate code, analyze files, summarize documents, interact with databases, and improve productivity using modern Large Language Models (LLMs).

Designed with a modern interface and high performance, Ibrahim AI Studio is suitable for developers, students, researchers, and business professionals.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/Ibrahim8047/Ibrahim-AI-Studio.git
```

Go to project folder

```bash
cd Ibrahim-AI-Studio
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```

---

# 🔑 Configuration

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_API_KEY
OPENAI_API_KEY=YOUR_API_KEY
```
