Desktop AI · Live on Microsoft Store

AI NexQuery

A hybrid AI query engine built for developers, data analysts, and business users. Published as a Windows desktop app under publisher MOHD AI.

Overview

What it does

Query MySQL & MSSQL databases in natural language, ask questions over your PDFs/DOCX/TXT via RAG, run ML analysis, and explore interactive visualizations — all in one app.

Live on Microsoft Store
Features

Core capabilities

  • Database Intelligence — natural language MySQL/MSSQL querying
  • Document QA — LangChain + FAISS vector search over PDF/DOCX/TXT
  • ML Studio — KMeans clustering, PCA, anomaly detection
  • Data Visualization — interactive charts and dashboards
Architecture

How it's built

A centralized AI Provider Manager routes requests through Gemini first, falling back to Groq (llama-3.3-70b-versatile) for reliability. Both API keys are served securely from a Supabase Edge Function rather than stored in the app.

Getting there

Shipping challenges solved

  • PyInstaller bundling — torch DLLs, tkinter data paths, sklearn .libs, missing DLLs
  • MSIX packaging errors — invalid filenames, signing/publisher CN mismatches
  • Microsoft Store policy certification — billing flow, AI content disclosure, free-tier limits
Security

Privacy & safety

End-to-end encrypted database connections. API keys are never stored locally — fetched securely per-session from a Supabase Edge Function.

End-to-end encrypted
